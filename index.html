    Sync across devices

    Your leads are saved to a private GitHub repository, so every device set up with the same token stays in sync.

    How to get a token
    1. Open github.com/settings/personal-access-tokens/new
    2. Repository access → Only select repositories → pick your data repo
    3. Permissions → Contents: Read and write → Generate
    4. Paste the token here, and on each device you use
