    Sync across devices

    Your leads are saved to a private GitHub repository, so every device set up with the same token stays in sync.

    How to get a token
    1. Open github.com/settings/personal-access-tokens/new
    2. Under Repository access, choose Only select repositories and pick your data repo
    3. Under Permissions → Repository permissions, set Contents to Read and write
    4. Generate the token and paste it above — repeat on each device you use
    The token is stored only in this browser.
